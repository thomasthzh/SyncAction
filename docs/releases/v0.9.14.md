# v0.9.14

品牌重新设计为Duet：两条独立弧轨围出共同空间，透明底石墨与蓝色，另有深底浅色、单色和16/32px光学版本。扩展、管理端、官网、分享封面与影片同源更新。

宣传片重做为32秒。第二、第三、第四个光标分别在3、8.5、14秒逐步进入，入场后持续留在画面中。新增全屏风景、巨幅暂停时间轴、四人协作英雄镜头与黑底品牌收束，重新制作原创配乐；光标运动采用错开的短移动、停读和少量修正。网站继续按需加载、原生播放、中文字幕和文字说明，保留前三版媒体链接。

影片是功能演绎：风景是原创AI生成静帧的镜头运动，界面和光标为矢量绘制；不是实际房间录屏。同步协议、数据库迁移和业务命令没有改变。安装后覆盖原扩展目录并重新加载，才会更新已安装图标。
