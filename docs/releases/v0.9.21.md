# SyncAction v0.9.21

- 观看卡打开固定的视频页面；成员头像打开其参与设备对应的共享页，不再要求本机提前绑定，也不会动态跳到另一台设备。
- “对齐一次”会先打开选定视频，按需授权、准备并识别媒体，再发送当前进度对齐；不加入播放组、不持续跟随，不发送播放或暂停命令。网页播放器自身行为以实际结果为准。视频、地址或房间变化会停止旧任务。
- 切到页面、成员或别的播放组时，保留“我的一起看”入口；可只返回本组，也可明确跟上当前视频。准备阶段可停止，已经打开的页面保留。
- 断线或尚未收到成员快照时显示状态待同步，收到真实快照后才显示在线人数及离线事实。本设备的就绪判断严格匹配当前播放组的视频与设备。
- 重新授权和恢复页面握手会补报兼容性证据；只缓存后台明确接纳的报告，发送失败或拒收后可正常重试。普通光标重绘保持去重，避免报告回放循环。

沿用现有服务端协议与兼容后端，无数据库迁移或新增权限。双方覆盖原扩展目录并重新加载。真实浏览器验收覆盖受控工作面和一次对齐流程；个人 Bilibili 登录及任意网站、DRM和网络条件不属于本次验收结论。
