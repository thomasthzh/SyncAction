# SyncAction v0.9.10

液态玻璃侧栏与交互体验更新，基于当前 MIT 脱敏公开仓库发布。客户端与服务端分开下载；不恢复此前私有仓库的历史或生产配置。

## 客户端

- 顶栏、工具栏、服务状态卡和弹窗加入真实背景边缘折射、明暗高光与本地流线背景。文字不参与位移；320–480px 侧栏布局保持紧凑。
- 密集页面和成员列表不逐行施加滤镜；位移图仅在尺寸变化时生成，没有持续鼠标/滚动重算。
- 系统减少透明度、减少动画及强制颜色偏好均有适配；长弹窗的玻璃层不随内容滚走。
- 改进页面搜索、窄屏分享入口、房间切换键盘操作、表单规则、错误焦点、密码显隐、忙态和重复提交保护。
- 操作反馈按服务器与房间隔离，过时请求不会向新上下文播报结果。
- 关闭侧栏时停止无消费者的 UI 投影，重新打开时获取最新完整快照。

## 服务端

保留公开版的管理员显式初始化及代理边界安全策略。协议与数据库模型无新增变更；服务端包不包含客户端或生产数据。

## 下载与安装

| 文件                                   | 用途                           |
| -------------------------------------- | ------------------------------ |
| `SyncAction-client-chrome-v0.9.10.zip` | Chrome 扩展，解压后加载        |
| `SyncAction-client-edge-v0.9.10.zip`   | Edge 扩展，解压后加载          |
| `SyncAction-server-v0.9.10.tar.gz`     | 自托管服务端源码与通用运行文件 |
| `SHA256SUMS.txt`                       | 三个安装资产的 SHA-256         |

**公开客户端的默认服务器 `https://syncaction.example.com`
是占位地址。安装后先在顶栏配置实际公共服务器。** 本次发布不提供共享服务器、默认管理员或预设密码。

升级扩展时覆盖原加载目录并点击“重新加载”，不要先移除旧扩展，以保留扩展身份、服务器配置和本地登录会话。

详细说明：[客户端](https://github.com/thomasthzh/SyncAction/blob/v0.9.10/docs/client.md)、[服务端](https://github.com/thomasthzh/SyncAction/blob/v0.9.10/docs/server.md)。本次不自动部署到现有服务器，也不代表已上架浏览器商店。

## 验收边界

发布验证覆盖静态检查、工作区测试、客户端构建、包内容边界与 SHA-256。浏览器视觉验收包括实际折射像素对比、窄栏溢出、长弹窗滚动与可访问性回退；不宣称真实用户设备帧率提升百分比。
