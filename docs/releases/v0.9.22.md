# SyncAction v0.9.22

- 关闭重开侧栏后，可找回上次准备的视频和原操作，明确选择继续或放弃；临时记录按服务器、账号和房间隔离，仅保留在本次浏览器会话中。
- 准备中和已提交分开显示。提交前先保存状态，重开不会自动重发跟随或 SEEK；结果未确认时先查看播放器。清理临时记录失败不会把已成功的播放操作误报为失败。
- 画笔、弹幕快捷键使用按键时的原生标签页与窗口。冷启动也能接入已有分享、授权流程；只有对应窗口可以领取任务，切页、切房或切账号后不会误用旧动作。
- 当前领播不会被旧跟随准备打断。后台初始化完成后再重新握手已打开页面，更新注入时识别运行时版本与存活状态；无法安全清理旧页面实例时，明确提示保存内容后刷新网页。
- 渲染依赖加载失败会释放失败缓存，允许后续明确重试。

沿用现有权限、协议和兼容后端，无数据库迁移、Cookie共享或新增主机权限。双方覆盖原扩展目录并重新加载；旧扩展上下文无法清理时需刷新已打开的共享页。本次浏览器验收针对受控工作面与恢复操作，未新增个人 Bilibili 登录或任意网站、DRM及网络条件的验收结论。
