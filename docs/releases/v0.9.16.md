# SyncAction v0.9.16

共享页面改为由插件显式提交、更新或移除。本机浏览器的普通跳转、关页和标签排序保持本地；跳转后的页面可以提交为共享更新，或在冲突时另行分享。移除共享页面前会明确确认影响。

修复共享页面在房间更新、重载和布局恢复后丢失协作绑定的问题，恢复在线状态、光标与页面工具的状态更新。未分享页面使用画笔或弹幕时，先完成当前页面的分享准备，再继续操作；授权说明采用紧凑布局，并提供可用的重试入口。

管理员控制台在认证失效时清理已加载的受保护数据和视图，取消未完成请求，并隔离旧响应。短暂的服务不可用保留当前工作状态，方便重试。原有管理员登录方式保留。

本次客户端变更不增加协议或数据库迁移。已有专用认证后端的部署须沿用兼容服务器构建，不能仅凭客户端版本替换其后端。更新扩展时覆盖原加载目录并重新加载；服务器更新不会自动替换已安装的客户端。

没有加入 Cookie 读取、Cookie 传输或共享画面传输。
