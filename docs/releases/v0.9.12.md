# SyncAction v0.9.12

这次更新重新组织侧栏的观看工作面、首次观看引导、网站授权和连接反馈。

- **一个观看工作面**：正在看什么、谁领播、当前进度、本人设备是否参与放在一起。有多个播放组时可以切换查看；查看与加入、对齐是独立操作。组更新保留阅读位置和键盘焦点。
- **更清楚地开始协作**：共享页面、允许网站、创建播放组按真实阶段推进。网站授权会说明允许后继续的操作；取消、失败重试和页面变更保留原有安全检查。
- **日常信息更轻，异常能够处理**：有房间时先继续协作，健康连接按需展开详情；重新检测服务与重新连接服务器各有明确入口。播放组管理收进就近展开区，领播者提议保持可见。
- **局部动画与结构优化**：播放组切换使用短暂的内容过渡，跟随状态连续更新；保留减少动态效果、减少透明度和强制颜色。观看、授权与连接样式分开维护，玻璃折射计算减少无效的内部像素运算。

Chrome /
Edge 请下载对应压缩包，解压后在扩展管理页使用“加载已解压的扩展程序”。升级已有安装时覆盖原目录并重新加载，可以保留浏览器中的配置与登录状态。首次使用需要配置可访问的 SyncAction 服务器。

服务器包适用于现有部署流程；这次升级没有新增数据库迁移或改变同步协议。
