# SyncAction v0.9.23

- 换设备时选择“在这台继续看”，会先打开原视频、按需授权并识别播放器，再将本组同步移到当前设备。保留原来的领播或跟随角色；准备阶段取消不会切走原设备。
- 设备切换请求与房间确认分开呈现。原设备、角色、视频或账号变化会停止旧任务；未确认的操作保留查看入口，不自动再次接管。关闭侧栏后仍可沿原准备记录明确继续。
- 活跃跟随者在本地播放器失效后仍可退出播放组；退出不再依赖本地媒体控制就绪，离线和成员权限校验保持不变。
- 普通光标坐标不再触发完整房间状态读取及投影。异步发送失败、恢复、授权变化和会话失效仍正常更新状态，不依赖下一次鼠标移动。

沿用现有权限、协议及兼容后端，无数据库迁移或新增主机权限。双方覆盖原扩展目录后重新加载。浏览器验收限定于受控工作面与当前改动；个人 Bilibili 登录、任意网站和网络条件未新增验收结论。
