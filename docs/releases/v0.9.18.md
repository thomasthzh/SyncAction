# SyncAction v0.9.18

领播者可以点击“用当前视频继续一起看”，在原播放组中切换到已经提交的当前视频，同伴保留原有跟随关系。无需关闭播放组、重新创建或让朋友再次加入。旧目标失效时，继续入口直接展开；未提交的页面仍须本人在插件内提交，不会自动公开本地浏览。

切换前重新识别当前主播放器，核对服务器、房间、标签页、页面版本、权限和当前领播设备。授权后继续切换原播放组，避免误创建新组。其他设备、跟随者和失效上下文不能代替领播切换。

Bilibili 在有明确且连续的分P/CID、主播放器和资源证据时，同一段视频的时长由估值变得精确后继续同步；跳转仍以实际时长为上限。复用原适配器，避免无意义地重建监听和中断临时倍速校准。分P、播放器或资源变化后，旧目标失效，旧临时倍速不会写入新视频。缺少分P证据的页面继续严格匹配，不猜测视频身份。

本版只更新客户端，沿用现有协议和兼容后端，无数据库迁移。双方更新原扩展目录并在扩展管理页重新加载即可。个人 Bilibili 登录、付费/DRM 和广泛网络条件不属于本次新增验收结论。
