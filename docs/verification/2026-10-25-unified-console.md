# v0.9.15 控制台验收

扩展侧栏与管理员控制台统一采用任务工作区、共同内容容器、就近操作和白色玻璃控制层。具体规则见
[设计约束](../design/task-oriented-ui.md)，安装和变更见 [客户端指南](../client.md) 与
[发布说明](../releases/v0.9.15.md)。

## 已覆盖的行为

- 两个独立 Chromium 配置、真实隔离后端：配置服务器、登录、选择房间、房主创建播放组、另一端打开领播页面并明确加入，播放、暂停和拖动进度同步。取消网站说明不执行业务命令，再次发起需要重新同意。
- 另一条首次进入链路：先选公开房间、注册、等待管理员批准、在独立管理员浏览器批准，再登录后自动续接同一个房间。快速输入不会被首次异步清空操作覆盖。
- 三个工作区保持挂载；搜索、播放组查看选择与滚动位置保留。切换不产生业务命令，不改变媒体参与关系。成员跳转按本人设备绑定判断；晚于媒体快照到达的成员状态会刷新可跳转信息。
- 管理员真实密码、TOTP 和 Cookie 登录；审批、自建对象的所有权转移、软删除和恢复，密钥生成、隐藏与撤销，设备聚合、筛选、刷新、退出。完整密钥仍只显示一次。
- 刷新与管理写入双向互斥，避免旧快照覆盖刚完成的密钥操作；未知结果和恢复配额冲突保留确认上下文。
- 320 / 420 / 480px 侧栏，320 / 390 /
  1440px 管理页面；长列表滚动、键盘任务导航、弹窗焦点约束与返回、减少动画、减少透明度和强制颜色检查。公开目录较长时仍可滚到底部。

测试数据库和账号均为本地合成对象，与生产及原有开发数据库隔离。生产发布另按实际提交和资产摘要验证，不用本地浏览器结果代替生产部署验收。

## 性能与结构范围

正常大厅不持续探测服务；设置打开时才挂载诊断组件，未配置的占位地址不发探测。密集列表不增加逐行背景滤镜，隐藏工作区不重复卸载和初始化。管理员纯呈现与 DOM 构造提取成模块，异步协调、请求失效与权威写入保持集中。没有新增运行依赖、数据库迁移或同步协议变更。

这些是实现及自动化证据；没有真人计时、代表性设备耗电或大样本研究，不宣称固定比例的效率或整机性能提升。

## 自动化边界

安装环境缺少浏览器技能的运行客户端，因此使用隔离 Playwright
Chromium，没有接管用户现有浏览器资料。扩展文档作为标签页打开；本地视频宿主在单独的验收 Manifest 副本预先授权，应用内说明、取消和同意均走真实控件。该部分不验证原生侧栏窗口或浏览器网站权限提示。媒体同步通过标准 HTMLMediaElement 事件验证，不等同于所有第三方视频网站兼容性验收。正式包保留原生产权限边界，不含本地验收地址。
