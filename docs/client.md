# SyncAction 客户端

客户端是 Chrome / Edge Manifest
V3 扩展，负责侧栏、浏览器标签执行、登录会话，以及获得授权后的页面协作。它不是服务端，也不包含数据库或管理员凭据。

## 安装和升级

1. 从 [v0.9.15 Release](https://github.com/thomasthzh/SyncAction/releases/tag/v0.9.15)
   下载对应浏览器的 `SyncAction-client-*.zip`。
2. 解压至固定目录，确认目录根部直接包含 `manifest.json`。
3. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式，选择“加载已解压的扩展程序”。
4. 打开 SyncAction 侧栏，在顶栏配置实际公共服务器地址。

**公开版默认的 `https://syncaction.example.com` 是占位域名，不提供公共服务。**
顶栏服务器按钮支持配置自托管 HTTPS 地址；本机开发允许 HTTP
loopback 地址。不要填管理员后台地址、带路径或查询参数的 URL。

更新时不要先移除旧扩展：把新版文件覆盖到原加载目录，再在扩展管理页重新加载。保持加载目录与扩展身份，才能保留原来的本地服务器配置和登录会话。加载到新目录可能获得新扩展身份，数据不会自动迁移。

## 使用

第一次一起看：

1. 在“配置服务器”中输入朋友或管理员提供的公共服务器地址，验证后保存并连接。
2. 从公开房间点加入；需要登录时按提示登录或注册。待批准账号由管理员批准后，点“批准后登录”继续原目标。
3. 在视频所在标签页打开侧栏，入房后点“开始一起看”。按提示分享当前页并阅读、同意当前网站的页面协作说明；浏览器另行要求网站权限时点允许。
4. 识别到可控制的视频后创建播放组，朋友入房后加入跟随。视频未准备好时先在网页播放一次，再按提示重试。

授权后若页面、房间或服务器变化，重新从当前页面发起操作。已经保存网站权限但启用失败时，可在原弹窗中重试。

房间中的“一起看”工作面会同时显示视频、领播者、进度和你在本设备上的参与状态。“打开领播页面”只打开对方所在页面；要持续跟随，请点击“加入播放组”。“对齐一次”只调整当前时刻，不加入播放组。

有多个播放组时，使用“查看播放组”切换查看；这不会改变你已参与的组，可用“返回我的播放组”回到原协作。尚未加入时，可展开“用当前视频新建播放组”；已参与另一组时需先显式退出。

房间内使用「观看／页面／成员」切换当前任务。切换只改变查看内容，搜索、播放组选择和滚动位置保留，不会加入或退出播放组。成员列表中可打开同伴当前页面，公开房间信息与成员管理也在这里。

顶栏「设置」集中管理账户、服务器和已授权站点；打开设置时检测服务是否响应，正常大厅不持续探测。房间摘要说明房间同步；观看工作面说明本人设备的媒体参与。看到异常时按就近提示恢复。领播者可展开“播放组管理”关闭本组；关闭会结束所有成员的本组协作。退出账户位于设置底部。

- 先浏览公开房间，再登录、注册或使用服务器支持的账户密钥登录；注册是否需要批准由服务器控制。
- 已登录用户可以创建、加入或申请加入房间。邀请与加入申请在对应列表和消息中心处理。
- 在房间中分享当前页、查看同伴当前页面、跳转或加入播放组。个人浏览器标签与房间共享标签有独立的同步保护边界。
- 在需要的网站上阅读协议并明确授权后，使用同页光标、`Alt+T` 弹幕或 `Alt+P`
  画笔。随机内容不一致时，位置型协作会保护性暂停，不会传输屏幕或整个 DOM。
- 登录会话保存在扩展本地存储；退出登录、服务端撤销或改变扩展身份可能要求重新登录。

## 开发分支：共享页面的提交与移除

以下为当前开发分支的新交互，已下载发行版的行为请以对应版本发布说明为准。

- 在插件内点“分享当前页”，才向房间提交页面。
- 在本地跳到新地址时，插件显示“有更新待提交”；点“提交页面更新”后，才更新原共享对象。
- 原共享对象已被其他人更新或移除时，先保留本地页面；可明确选择“作为新页面分享”。
- 在插件的页面列表点“打开”只打开所选一页；普通浏览器关闭标签页不删除房间记录，也不会强行重开。
- 从房间撤下页面，请在插件点“移除”并确认；仍绑定该共享页的成员标签页也可能关闭。

提交的是页面地址，不会复制推荐列表、登录态或网页内部数据。当前同步模式不读取或分享 Cookie；两个相同网址的个性化页面仍可能不同，此时位置协作会暂停。媒体播放同步也不等同于共享视频画面。

## 液态玻璃与可访问性

顶栏、底栏、状态卡和弹窗使用背景边缘位移；文字和交互控件独立渲染。密集页面列表不使用逐行背景滤镜。

系统请求“减少透明度”时会回退为纯色；请求减少动画时关闭入场与过渡效果；强制颜色模式使用系统颜色。发现界面没有玻璃效果时，先检查系统可访问性设置。效果经当前 Chromium 验证，不承诺与原生图形着色器完全一致。

## 自行构建

在仓库根目录安装依赖后执行：

```sh
pnpm --filter @syncaction/extension build
pnpm --filter @syncaction/extension build:edge
```

未设置 `WXT_PUBLIC_SERVER_URL` 时，输出位于 `apps/extension/.output/chrome-mv3` 与
`apps/extension/.output/edge-mv3`。若将该变量设置为不同于占位地址的服务源，无论是自托管 HTTPS 还是本机 HTTP，输出目录都会改为
`apps/extension/.output/chrome-mv3-local` 与 `apps/extension/.output/edge-mv3-local`。

该变量目前只影响构建权限、输出目录及页面协作排除地址，不会内置新的运行时默认服务器配置。新安装仍使用占位配置，必须在顶栏手动添加并选择实际公共服务器；已有安装保留原本选择的服务器。

本地开发可使用 `pnpm local:client:chrome` / `pnpm local:client:edge`，加载后在顶栏添加并选择
`http://127.0.0.1:29373`。对应 `*-mv3-local` 输出不应冒充正式发布包。
