打开完整使用指南 ↗
  1. 1

    装好扩展，打开侧栏

    下载 Chrome 或 Edge 的 ZIP，解压到固定文件夹。在浏览器扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。

    选择你的浏览器 ↓
  2. 2

    连接服务器，完成登录

    在侧栏顶栏配置实际的公共服务器地址。按提示登录或注册；账号待批准时，等管理员批准后，点击侧栏“批准后登录”继续。也可连接朋友提供的服务器。

  3. 3

    进入同一房间，开始协作

    创建或加入房间，分享当前页。在“开始一起看”中完成网站授权，创建播放组；朋友打开对应页面，加入播放组后开始跟随。

    房间可能需要邀请或审批，以服务器与房间规则为准。

常见问题

需要每个人都安装吗？

参与网页协作的朋友需要在各自的 Chrome 或 Edge 安装扩展，连接同一台公共服务器，进入同一个房间。视频仍由各自的网页播放，需要各自具备对应内容的访问权限。

所有网站和视频都支持吗？

不能保证。媒体需要能被扩展识别并控制；DRM 保护、没有有限时间轴的直播，或特殊播放器可能不适用。页面内容不一致时，位置型协作会保护性暂停。遇到问题可先在网页播放一次，再按侧栏提示重试。

查看另一播放组，会改变我正在跟随的组吗？

不会。查看和加入是不同动作；打开页面或查看另一组，不会自动改变本设备正在参与的播放组。需要本人明确加入后才开始跟随。

网站授权后，会共享什么数据？

分享到房间的页面地址和标题会成为房间信息。按网站开启页面协作后，会发送内容兼容性摘要、量化位置、媒体状态，以及你主动发送的弹幕和绘制内容；该通道不发送 Cookie、密码、表单文字、网页正文、完整 DOM、截图或视频流。

网站权限可在侧栏管理并撤销。撤销权限会停止后续对应协作，已分享的页面与消息不会因此自动删除。登录会话保存在扩展本地；服务器仍处理账号、房间和消息等业务数据。

服务在线，为什么还没有一起播放？

服务在线表示能连接服务器；房间已同步表示房间信息已经同步。要跟随视频，还需打开对应页面、完成网站授权，并明确加入播放组。观看工作面会单独显示本设备是否参与，按就近提示继续即可。

可以自己部署服务器吗？

可以。客户端与服务端代码均在公开仓库中，服务器可自行部署。客户端填写你实际的 HTTPS 公共服务地址，不要填管理员后台地址。阅读服务器部署指南。
